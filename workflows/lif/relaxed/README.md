# `lif/relaxed`

`lif/aims` with a GCMC walk that relaxes after each exchange: the minimal diff for a sampler change.

```bash
python workflows/lif/relaxed/run.py --dry-run
python workflows/lif/relaxed/run.py
```

Explained in [`docs/workflows.md`](../../../docs/workflows.md#lifaims-and-lifrelaxed). The same shape runs
in seconds as [`examples/gcmc/`](../../../examples/gcmc/).
