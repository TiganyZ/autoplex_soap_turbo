# LiF seed data

`example_clusters.xyz` is generated by `make_clusters.py` and is **not reference
data**. Its dipoles come from putting +1 on every Li and −1 on every F, which
overstates the charge transfer — for the LiF diatomic it gives 1.56 e·Å against
a measured 1.32. It exists so that `run.py --dry-run` has something to read and
a fresh installation can be exercised before any VASP has run.

Replace it with frames whose dipoles came out of the VASP stage, then point
`dataset.initial` at your file.

Every frame is **neutral** — equal numbers of Li and F. That is required, not
incidental: a charged system's dipole depends on where the origin is put, so it
is not a well-defined quantity, and the VASP stage refuses to compute one.

`lif_unit.xyz` is configuration rather than data: it is the rigid neutral unit
the grand-canonical sampler inserts and removes (`sampling.mc_molecule_files`).
Exchanging this instead of individual ions is what keeps every sampled
configuration neutral.
