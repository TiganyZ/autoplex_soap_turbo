# `lif/aims`

The LiF dipole model against FHI-aims on a frozen LiF potential (Mode B), gated.

```bash
python workflows/lif/aims/run.py --dry-run
python workflows/lif/aims/run.py
```

Explained in [`docs/workflows.md`](../../../docs/workflows.md#lifaims-and-lifrelaxed). The same shape runs
in seconds as [`examples/gcmc/`](../../../examples/gcmc/).
