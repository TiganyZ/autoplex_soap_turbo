# `water_density`

Extends `water_ladder`'s data over cluster density as well as size.

```bash
python workflows/water_density/run.py --dry-run
python workflows/water_density/run.py
```

Explained in [`docs/workflows.md`](../../docs/workflows.md#water_density). The same shape runs
in seconds as [`examples/cluster_ladder/`](../../examples/cluster_ladder/).
