# `water_dipole_md`

Water dipole model, sampled by turboGAP MD on the frozen CHO GAP, gated on `data/test_all.xyz`.

```bash
python workflows/water_dipole_md/run.py --dry-run
python workflows/water_dipole_md/run.py
```

Explained in [`docs/workflows.md`](../../docs/workflows.md#water_dipole_md-water_dipole_md_uncertainty-water_dipole_gcmc). The same shape runs
in seconds as [`examples/frozen_potential_md/`](../../examples/frozen_potential_md/).
