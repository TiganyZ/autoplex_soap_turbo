# `water_dipole`

A water dipole and polarizability model, plus an energy model, from one batch of
FHI-aims DFPT per iteration (Mode A).

```bash
python workflows/water_dipole/run.py --dry-run
python workflows/water_dipole/run.py
```

The checked-in seed has synthetic dipoles. Replace it with your own data
(`data/README.md`).
