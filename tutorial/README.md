# Tutorial

`autoplex_soap_turbo_tutorial.ipynb` takes a new user from nothing to a trained
Li–C–O potential, a database pooled across users, and LAMMPS/MADlib runs that
match X-ray and NMR spectra. Open it with the `autoplex_venv` kernel; every cell
runs with its switches off.

| | |
|---|---|
| `figures/` | the diagrams the notebook shows |
| `madlib/` | the LAMMPS decks and two helper scripts for Parts 5–6 |
| `runs/` | what the notebook writes when it runs (gitignored) |
